# Career Analytics – Student Placement & Salary Insights

## 📌 Project Overview
This project focuses on analyzing student placement and salary information using Python, SQL Server, and Power BI.

The objective is to understand placement trends and compare salary details across different courses, companies, job roles, and locations.

## 🎯 Project Objectives
- Analyze student placement information.
- Compare salaries across different locations.
- Explore company-wise and job-role-wise placements.
- Understand yearly placement trends.
- Create interactive Power BI dashboards.

## 🛠️ Tools & Technologies
- Python (Google Colab)
- Pandas
- NumPy
- SQL Server
- Power BI
- Microsoft Excel

## 📂 Project Workflow
1. Downloaded a publicly available secondary dataset from Kaggle.
2. Imported the dataset into Google Colab.
3. Cleaned and prepared the data using Python, Pandas, and NumPy.
4. Imported the cleaned dataset into SQL Server.
5. Performed data analysis using SQL queries.
6. Connected SQL Server to Power BI.
7. Created four interactive dashboards.

## 📊 Power BI Dashboards
1. Learning to Career Analytics
2. Education & Placement Analysis
3. Company & Job Role Analysis
4. Salary & Placement Insights

## 📈 Key Analysis Areas
- Student placements
- Average and maximum salary
- Course and branch analysis
- Company and job-role analysis
- Location-wise salary comparison
- Yearly placement trends

## 💡 Project Outcome
Created four interactive Power BI dashboards to analyze student placements, salary patterns, companies, job roles, and locations.
